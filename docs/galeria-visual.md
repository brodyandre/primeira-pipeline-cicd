# 🖼️ Galeria Visual do Laboratório

Esta página foi preparada para receber as **8 capturas de tela** que comprovam a execução do laboratório de CI/CD ponta a ponta.
Ela funciona como um complemento visual do [README principal](../README.md) e ajuda bastante na apresentação do projeto para recrutadores.

> [!TIP]
> O ideal é salvar todas as imagens em `assets/screenshots/` com os nomes sugeridos abaixo. Depois disso, basta trocar o bloco
> `> Aguardando imagem...` pelo markdown pronto de cada seção.

## 🛠️ Como preencher esta página

1. Salve os arquivos PNG na pasta `assets/screenshots/`.
2. Mantenha os nomes exatamente como listados abaixo.
3. Em cada seção, substitua o bloco de placeholder pelo markdown já preparado.
4. Faça `commit` e `push` para que a galeria apareça renderizada no GitHub.
